# Space Voyage

A space-themed web game where players navigate through different difficulty levels to achieve the highest score.

## Game Pages

- **index.html** - The main landing page and entry point for the Space Voyage game
- **low.html** - Low difficulty level gameplay
- **medium.html** - Medium difficulty level gameplay  
- **high.html** - High difficulty level gameplay
- **leaderboard.html** - View player scores and rankings across all difficulty levels
- **mobile.html** - Mobile-optimized version of the game

## How to Play

1. Start at the **index.html** page to begin your space voyage
2. Choose your difficulty level (Low, Medium, or High)
3. Navigate through space, collecting points and avoiding obstacles
4. Compete for the top spot on the **leaderboard**
5. Play on mobile devices using the dedicated **mobile.html** interface
